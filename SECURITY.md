# Security

Ferrite serves files uploaded by users from its own origin, so security reports are taken seriously. [docs/security.md](docs/security.md) describes what was reviewed and the known limits.

## Reporting a vulnerability

Please do not open a public issue. Use GitHub's private reporting: on the repository, go to **Security > Report a vulnerability**. Include what you found, the version or commit, and steps to reproduce it. If you cannot use GitHub, say so in a plain issue without details and a private channel will be arranged.

You can expect an acknowledgement within a few days. This is a small project run by one person, so there is no bug bounty and no guaranteed timeline, but reports are fixed promptly and credited if you wish.

## Supported versions

Only the latest release (and `main`) receives fixes.
